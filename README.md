# Rainfall Analysis and Planting Advisory
### DESCRIPTION
#### This project analyses monthly rainfall patterns across five Kenyan counties using Python and NumPy to identify suitable planting windows.

## How to Run

1. Install the required libraries using `pip install -r requirements.txt`.
2. Open `rainfall_analysis.ipynb` in Jupyter Notebook or Google Colab.
3. Run all cells from top to bottom to generate the analysis and CSV summary.

## Planting Advisory

- Use each county's recommended two-month planting window based on combined rainfall.
- Consider dry-month counts and local rainfall patterns when planning planting activities.
- Verify rainfall forecasts before planting because historical data does not guarantee future rainfall.
